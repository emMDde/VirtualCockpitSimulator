Detailed Description

Model matematyczno-fizyczny zachowania samolotu w przestrzeni.

Klasa odpowiada za przetwarzanie surowych sygnałów z kontrolera na fizyczne wychylenia i prędkości kątowe obiektu. Realizuje algorytmy bezwładności lotu, integrację czasową położeń oraz funkcję autopoziomowania (auto-leveling) dla obu osi obrotu (X i Y), symulując zachowanie stabilizatora lotu.

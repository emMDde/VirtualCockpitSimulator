Detailed Description

Klasa reprezentująca nakładkę startową oraz ekran utraty połączenia z kontrolerem.

Klasa służy do wyświetlania ekranu startowego oraz zarządza uruchomieniem wszystkich elementów odpowiedzialnych za symulację (za pomocą przycisku). Wyświetla animowany komunikat o stanie połączenia oraz zarządza przyciskiem startu/wznowienia gry.

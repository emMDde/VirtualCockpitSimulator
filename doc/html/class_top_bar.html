Detailed Description

Górny pasek nawigacyjny aplikacji.

Klasa odpowiedzialna za wyświetlanie i obsługę górnego paska interfejsu. Zawiera przyciski sterujące motywem, językiem oraz wizualny wskaźnik (diodę) statusu połączenia z kontrolerem STM32.

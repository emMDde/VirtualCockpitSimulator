Detailed Description

Klasa reprezentująca dedykowany widok/stronę z prezentującą dane lotu.

Klasa dziedziczy po QWidget i służy jako kontener dla podelementów interfejsu użytkownika, takich jak panel dolny (BottomBar) oraz główny obszar prezentacji danych telemetrycznych (FlightDataArea). Zarządza dystrybucją sygnałów sterujących oraz pośredniczy w dynamicznej zmianie motywów graficznych swoich komponentów.

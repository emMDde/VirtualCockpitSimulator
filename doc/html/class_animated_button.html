Detailed Description

Przycisk z customowym stylem i opcjonalną animacją kółka.

Klasa definiuje bazowy styl przycisku, efekty przy najechaniu na niego kursorem i kliknięciu. Rozszerza ona QPushButton o możliwość wyświetlania animowanego elementu dekoracyjnego (kółka), który przesuwa się po najechaniu myszą. Obsługuje dynamiczną zmianę języka oraz dwa predefiniowane motywy graficzne.

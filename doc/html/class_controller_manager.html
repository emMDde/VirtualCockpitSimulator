Detailed Description

Zarządza komunikacją z zewnętrznym kontrolerem poprzez port szeregowy (UART).

Klasa odpowiada za automatyczne wyszukiwanie odpowiedniego kontrolera w systemie, bezpieczny odczyt i parsowanie strumienia danych binarnych, weryfikację sum kontrolnych CRC oraz obsługę awarii (watchdog braku danych oraz automatyczne wznawianie połączenia). W przypadku braku fizycznego urządzenia, umożliwia pracę w trybie demonstracyjnym/testowym.

Detailed Description

Główny widok aplikacji integrujący trójwymiarową symulację lotu z interfejsem użytkownika.

Klasa dziedziczy po QWidget i stanowi kontener (stronę) organizujący kluczowe elementy symulatora: górny panel nawigacyjny (TopBar), silnik renderujący obszar symulacji (SimulatorArea), nałożony na niego wirtualny horyzont (VirtualHorizon) oraz ekran pauzy/oczekiwania (EntryOverlay). Pełni rolę dystrybutora sygnałów pomiędzy poszczególnymi komponentami tej strony.

Detailed Description

Główne okno aplikacji zarządzające cyklem życia programu i globalną architekturą widoków.

Klasa stanowi główny punkt wejściowy interfejsu graficznego (GUI). Odpowiada za inicjalizację systemu zarządzania stronami (QStackedWidget), integrację niskopoziomowego menedżera kontrolera (ControllerManager) z modelem fizyki lotu (FlightMathModel) oraz globalną dystrybucję sygnałów sterujących i danych telemetrycznych w aplikacji.
